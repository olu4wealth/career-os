# Career OS — Future, Growth & Monitoring

Personal operating system for a Future, Growth & Monitoring Officer (insurance).
Track → Analyse → Identify → Explain → Recommend → Act → Review.

**Live demo (no install):** enable GitHub Pages on this repo (`/docs`) and open the Pages URL.
Data stays in your browser (localStorage).

**Run locally (with Python database):**
```
python server.py
```
then open http://127.0.0.1:8130. No dependencies — stdlib only.
